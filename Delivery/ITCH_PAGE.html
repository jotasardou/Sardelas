Aprenda. Desvie. Evolua.

Você é o agente N-01. Um laboratório digital perdeu suas conexões de conhecimento. Recupere os dados, escape dos bugs e use o que aprendeu sobre Machine Learning para reativar seus seis setores.

NeuroRun combina uma arena 2D com 18 desafios curtos. Cada resposta vem com uma explicação. Você vai passar por dados, história da IA, NumPy, scikit-learn, matemática, generalização e responsabilidade.

Como jogar

  1. Colete os três dados dourados de cada setor.
  2. Desvie dos bugs cor-de-rosa; use o dash para escapar.
  3. Entre no núcleo verde no centro da arena.
  4. Acerte os três desafios para liberar o próximo setor.

Você começa cada setor com 70 segundos e três vidas. Dados dão +3 segundos; erros no quiz custam 8 segundos. A leitura fica pausada, então aproveite as explicações. Se perder, reinicie o setor ou volte ao menu. Não há segredos obrigatórios.

Controles

  • Mover: WASD, setas, analógico esquerdo ou direcional.
  • Dash: Espaço, Shift esquerdo ou B no controle Xbox.
  • Pausa: Esc ou Start.
  • Respostas: teclas 1, 2 e 3, clique, ou direcional + A.
  • Menus: mouse, Tab/Enter, ou direcional + A.
  • Áudio: botão SOM / MUDO.

Jogue em um navegador desktop. Clique na área do jogo para dar foco ao teclado. O botão de tela cheia fica no rodapé do player.
